Features

Everything you need to ship data products

Built on Turso (Rust/SQLite) — edge-ready, multi-tenant, and fully self-hosted.

🔐

Multi-Tenant Isolation

Every user gets their own database namespace. Cross-tenant access is blocked at the API layer.

⚡

Turso Engine

Built on libSQL, the open-source fork of SQLite. Embeddable, fast, and SQL-compatible.

🔑

JWT + OAuth

Built-in JWT authentication with Google Sign-In. Role-based access (admin / client user).

📊

Analytics Dashboard

Real-time charts with 2D (Chart.js) and 3D (Three.js) views. Toggle between them live.

🚦

Rate Limiting

Token-bucket rate limiter per IP. Configurable max queries per minute. Prevents abuse.

🔌

REST API

Full CRUD for databases, SQL execution, and user management. Works with fetch, curl, any HTTP client.
