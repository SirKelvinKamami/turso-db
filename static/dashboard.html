Quick Start

Integrate TursoDB into your projects

REST API

API Base URL:

https://turso-db-8svn.onrender.com

List databases:

curl -H "Authorization: Bearer TOKEN" \
/v1/databases
JavaScript
const API = "/v1";
async function query(db, sql) {
const r = await fetch(`${API}/databases/${db}/query`, {
method: "POST",
headers: { "Authorization": `Bearer ${token}`, "Content-Type": "application/json" },
body: JSON.stringify({ sql })
});
return r.json();
}
Python
import requests
API = "https://turso-db-8svn.onrender.com/v1"
HEADERS = {"Authorization": "Bearer TOKEN"}
def query(db, sql):
r = requests.post(f"{API}/databases/{db}/query", json={"sql": sql}, headers=HEADERS)
return r.json()
